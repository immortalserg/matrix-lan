# Matrix LAN — чистая установка

Matrix LAN объединяет переписки разных служб в Element. Synapse хранит комнаты и сообщения в PostgreSQL 16. WhatsApp, Telegram и LinkedIn используют отдельные базы в том же PostgreSQL. Некоторые другие мосты используют собственные SQLite-файлы, каталоги медиа и сессий. Все хранилища создаются при первом запуске.

Комплект содержит установщики, шаблоны и исходники локальных изменений. В нём есть интерфейс подключения и контроля аккаунтов, поиск «Добавить клиента» для Telegram, WhatsApp и IMO, настройки уведомлений и обработчики вложений. Для передачи этого проекта другому ИИ передайте репозиторий вместе с [AGENTS.md](AGENTS.md).

## Требования

- Linux x86-64, Python 3.10 или новее, Docker Engine и плагин Docker Compose v2.
- Доступ к Docker Hub, GHCR, MCR, `dock.mau.dev` и репозиториям зависимостей Docker, Go и Python во время первой сборки.
- Для полной установки с несколькими Chromium разумно предусмотреть от 8 ГБ ОЗУ и от 20 ГБ свободного места. Для проверки Synapse без мостов можно начать с `--core`.
- Для доступа с другого компьютера выберите постоянное имя или адрес Linux-сервера. Значение `--host` также становится доменом Matrix ID, поэтому задайте его до первой установки.

Подготовка Docker и базы описана в [Docker Compose](https://docs.docker.com/compose/install/linux/) и [документации Synapse по PostgreSQL](https://element-hq.github.io/synapse/latest/postgres.html).

## Установка

Распакуйте ZIP в новый каталог и перейдите в папку `Matrix-LAN` на Linux-хосте. Запустите установщик.

```bash
sudo bash install.sh
```

По умолчанию Element доступен на этом компьютере по `https://localhost:18081/`. Для работы по локальной сети подставьте свой DNS-адрес или IP и разрешите доступ к выбранному порту только из нужной сети. В следующей команде имя `matrix.home.arpa` должно разрешаться в адрес сервера.

```bash
sudo bash install.sh --host matrix.home.arpa --bind 0.0.0.0 --port 18081 --owner owner
```

Установщик создаёт закрытый каталог `runtime/`, генерирует ключи мостов, пароль владельца и пароли ролей PostgreSQL, запускает Synapse и регистрирует первый локальный аккаунт. После регистрации запускаются Element, Caddy и выбранные мосты. Повторный `sudo bash install.sh` продолжает установку с теми же ключами и паролем.

Следующие команды покажут начальный пароль, путь к локальному сертификату и состояние сервисов. Выполняйте их на сервере.

```bash
sudo python3 install.py password
sudo python3 install.py ca
sudo python3 install.py status
```

Имя входа для примера выше — `@owner:matrix.home.arpa`. Сертификат `runtime/caddy-root.crt` создаёт Caddy для этой установки. Импортируйте этот корневой сертификат в доверенные сертификаты клиентских устройств, которыми управляете. Сам Matrix и базы наружу не публикуются: Docker публикует только выбранный HTTPS-порт Caddy, а режим по умолчанию слушает только loopback.

## Мосты и Telegram

Полный запуск готовит WhatsApp, Facebook Messenger, Instagram, X, TikTok, LinkedIn, Gmail, IMO, WeChat, Taobao, Pinduoduo, Threads, Одноклассники и VK. Подключите собственные аккаунты в Element через «Подключить новый аккаунт». QR, подтверждения сервисов и настройки дополнительной защиты проходят после запуска. Входящие бизнес-страниц Facebook требуют отдельной интеграции и доступа к странице. Этот комплект использует имеющийся мост личного Messenger.

Для Telegram нужен собственный `api_id` и `api_hash`. Получите их по инструкции [Telegram](https://core.telegram.org/api/obtaining_api_id). Создайте за пределами репозитория свой JSON с двумя полями, как в [примере](templates/telegram.example.json), и ограничьте к нему доступ. Передайте путь к нему при первом запуске.

```bash
sudo bash install.sh --telegram-config /path/to/telegram.private.json
```

Если полный комплект уже запущен, добавьте Telegram отдельной командой.

```bash
sudo python3 install.py enable-telegram /path/to/telegram.private.json
```

Для Gmail используйте отдельный пароль приложения своего почтового аккаунта. Мосты, использующие веб-клиенты, зависят от доступности внешних сервисов и их текущих условий входа. Подключайте их по одному и сначала проверьте двусторонний обмен со своим тестовым аккаунтом. Подключение к внешнему аккаунту может импортировать историю этого аккаунта в зависимости от настроек моста. В ZIP история отсутствует.

Для настройки WhatsApp и IMO откройте в Element мастер подключения и отсканируйте QR телефоном с нужным аккаунтом. После подключения выберите раздел этого аккаунта, нажмите «+ → Добавить клиента», найдите свой тестовый контакт и откройте чат. Для Facebook нужен действующий личный профиль Messenger, для WeChat используется встроенный шлюз. Если внешний сервис запросил подтверждение, завершите его в официальном интерфейсе. Статус моста и его журнал помогут отличить ограничение внешнего аккаунта от ошибки внутри Matrix LAN.

Уведомления MSB-CBMRS можно включить при наличии своего совместимого API. Передайте разрешённый адрес сервера при установке, например `--cbmrs-origin https://cbmrs.example.test:8443`. Затем заполните путь API и ключ в настройках Matrix. Для сервера с собственным CA сохраните его открытый сертификат в `runtime/state/accounts/msb-cbmrs-ca.pem` с правом чтения у UID 10001.

## Отдельный запуск и обновление

Режим `--core` запускает PostgreSQL, Synapse, Element и Caddy без мостов. Для проверки на том же Linux-хосте используйте отдельный каталог, порт и имя проекта Docker Compose.

```bash
sudo python3 install.py --runtime /var/lib/matrix-lan-test prepare --core --host localhost --port 19081 --project matrix-lan-test
sudo python3 install.py --runtime /var/lib/matrix-lan-test start
sudo python3 install.py --runtime /var/lib/matrix-lan-test status
```

Для остановки выполните `sudo python3 install.py stop`. Команда останавливает контейнеры, сохраняя данные. Для диагностики используйте `sudo docker compose -f runtime/compose.yaml ps` и `sudo docker compose -f runtime/compose.yaml logs --tail=100 <имя-сервиса>`. Полная развёрнутая конфигурация Compose содержит сгенерированные секреты.

Вложениями Synapse управляет модуль `media_retention.py`. По умолчанию срок хранения составляет два календарных месяца. Скрипт `services/wechat/retention.py` проверяет кеш нативного WeChat, если администратор укажет каталог адаптера. По умолчанию он показывает объём просроченных файлов. Для применения используется `--apply`. У Matrix, PostgreSQL и мостов есть независимые каталоги и Docker-тома, их надо учитывать в резервной копии.

Для проверки установки по умолчанию используйте локальный CA. Первый запрос проверяет доступ к Matrix через Caddy, второй подтверждает, что Synapse создал таблицы в PostgreSQL.

```bash
sudo python3 install.py ca
sudo curl --fail --cacert runtime/caddy-root.crt https://localhost:18081/_matrix/client/versions
sudo docker compose -f runtime/compose.yaml exec -T db psql -U postgres -d synapse -c 'SELECT count(*) FROM rooms;'
```

Исходники хранятся отдельно от локальных данных. `prepare` копирует приложения в `runtime/build/`, подставляя адрес новой установки. При обновлении сделайте резервную копию `runtime/state/` и PostgreSQL. Сверьте новые исходники и конфигурацию на отдельном стенде, прежде чем обновлять существующее развёртывание. Установщик предназначен для чистого развёртывания и продолжения первого запуска. Он не переносит базы между серверами.

## Что публиковать на GitHub

Опубликуйте файлы из этого ZIP. Команда `sha256sum -c MANIFEST.sha256` из распакованной папки проверит их целостность. Держите `runtime/`, свои файлы с настройками Telegram, резервные копии, файлы браузерных сессий и локальные ключи вне Git. Перед первым коммитом просмотрите `git status --short`. Встроенный `.gitignore` исключает стандартный каталог установки и распространённые форматы локальных данных.

Компоненты сторонних проектов сохраняют свои лицензии. См. [THIRD_PARTY.md](THIRD_PARTY.md).
