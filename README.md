# Matrix-LAN

Самостоятельно размещаемый агрегатор мессенджеров на Matrix Synapse и Element для дома и небольших организаций.

## Архитектура

Один контейнер matrix-bridges управляет процессами мостов, отдельными конфигурациями и журналами. Synapse, Element, Caddy, authorization и chat-api остаются отдельными сервисами. PostgreSQL 16 — общий сервер баз данных. Нативный шлюз WeChat остаётся отдельным техническим сервисом. Браузерные профили и медиа хранятся в файловой системе.

Целевая модель доступа: обычный пользователь видит собственные аккаунты и переписки, суперадминистратор управляет всей системой. Изоляция реализуется на уровне приложения.

**Статус:** ветка разработки новой архитектуры. Полная сборка, совместимость всех мостов с PostgreSQL и многопользовательская работа ещё требуют проверки.

## Требования

Linux x86-64, Docker Engine, Docker Compose v2. Для полной сборки рекомендуется не менее 8 ГБ ОЗУ и 20 ГБ свободного места. Необходим доступ к реестрам образов и репозиториям зависимостей.

## Чистая установка (после завершения тестирования)

```bash
sudo bash docker-install.sh prepare --host localhost --bind 127.0.0.1 --port 18081
sudo bash docker-install.sh unified-preflight
sudo bash docker-install.sh start
```

Откройте https://localhost:18081/. Первый пользователь регистрируется через веб-интерфейс и становится суперадминистратором. Последующие пользователи регистрируются по приглашениям. Установщик не создаёт пользователя автоматически.

Для локальной сети задайте постоянное имя сервера и подходящий адрес привязки до установки. Корневой сертификат Caddy можно получить командой `sudo bash docker-install.sh ca`.

## Мосты

Целевой комплект: WhatsApp, Telegram, Signal, Facebook Messenger, Instagram, X, TikTok, LinkedIn, Email, Threads, OK, VK, IMO, WeChat, Taobao и Pinduoduo.

Управление процессами и настройками осуществляется через веб-панель. Telegram требует api_id и api_hash, полученные на https://my.telegram.org/. Не все мосты пока подтверждены функциональными тестами.

## Диагностика

```bash
sudo bash docker-install.sh status
sudo bash docker-install.sh unified-preflight
sudo docker compose -f runtime/compose.yaml logs --tail=100 matrix-bridges
```

Предварительная диагностика проверяет конфигурацию Compose, сборку образа и пути запуска, но не подтверждает обмен сообщениями.

## Тестовая переустановка

```bash
sudo bash docker-install.sh reinstall --yes
```

Внимание: команда удаляет локальные данные, аккаунты, сессии и тома PostgreSQL тестовой установки. Исходники Git сохраняются. Для остановки без удаления данных используйте `sudo bash docker-install.sh stop`.

Не публикуйте runtime, ключи, пароли, браузерные профили и резервные копии. Лицензии сторонних компонентов: [THIRD_PARTY.md](THIRD_PARTY.md).
